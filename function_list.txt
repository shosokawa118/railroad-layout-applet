FUNCTION API SPECIFICATION
FILE: function_list.txt
REPO: shosokawa118/railroad-layout-applet
BRANCH: develop
DESCRIPTION: この一覧は、レイアウト編集アプリの公開/内部関数を API 仕様書に近い形式で整理したもの。各関数は、シグネチャ、引数、戻り値、用途を含む。

---

FUNCTION: recordAction
FILE: editor-actions.js
SIGNATURE: recordAction(action)
PARAMS:
  - action: Object — 履歴に記録するアクション。例: { type: 'MOVE'|'ADD'|'DELETE'|'CYCLE_NODE', ... }
RETURNS: void
USAGE: 履歴アクションを記録し、Redo スタックを初期化する。操作前の選択状態を self.selectionBefore として自動記録する。

---

FUNCTION: undoLayout
FILE: editor-actions.js
SIGNATURE: undoLayout()
PARAMS: なし
RETURNS: void
USAGE: Undo スタックから直前のアクションを取り出し、executeAction(action, true) を呼び出して逆実行する。

---

FUNCTION: redoLayout
FILE: editor-actions.js
SIGNATURE: redoLayout()
PARAMS: なし
RETURNS: void
USAGE: Redo スタックから次のアクションを取り出し、executeAction(action, false) を呼び出してやり直す。

---

FUNCTION: executeAction
FILE: editor-actions.js
SIGNATURE: executeAction(action, isUndo)
PARAMS:
  - action: Object — 実行対象の履歴アクション
  - isUndo: boolean — true なら逆方向、false なら順方向で実行
RETURNS: void
USAGE: MOVE / ADD / DELETE / CYCLE_NODE を含むアクションを実行または逆実行する。影響を受ける flexible rail を考慮して再描画や状態更新を行う。
