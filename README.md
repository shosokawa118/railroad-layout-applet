# Railroad Layout Applet (RLA)

Nゲージなどの鉄道模型レールをキャンバス上で直感的に配置・接続し、レイアウトを設計できるWebアプレットです。  
パーツ同士のジョイント吸着（スナップ接続）や、選択中のレールから連続して繋がっていく自動接続機能、各種レールシステムのカタログ拡張に対応しています。

---

## 主な機能・特徴

* **直感的な操作**: マウスドラッグでレールを自由に配置・移動・回転
* **スマート接続機能**:
  * ジョイント同士を近接させることによるスナップ接続
  * 既存レールを選択した状態での連続自動接続
---

## 利用方法（操作ガイド）

### 基本操作

1. **パーツの追加**:
   * ヘッダーの「レール規格」セクションで規格を選択します。
   * 「直線」「曲線」「ポイント」のカテゴリタブを切り替え、表示されたパーツパレットから配置したいレールをクリックしてキャンバスに追加します。
2. **パーツの移動・回転・選択**:
   * **移動**: レールをドラッグ＆ドロップします。
   * **回転**: レールを選択し、回転ハンドルを操作します。
   * **範囲選択**: キャンバス上をドラッグして複数パーツをまとめて選択できます。
   * **追加選択**: `Shift` キーを押しながらクリックすると追加選択できます。
   * **連結レール選択**: 右クリックメニューの「連結レールを選択」または `Ctrl+Shift+A` で、繋がっているレールを一括選択できます。
   * **すべて選択**: 右クリックメニューの「すべて選択」または `Ctrl+A` でキャンバス上の全レールを選択できます。
3. **レールの接続**:
   * **手動スナップ**: レールの端点（ノード）を別のレールの端点に近づけると自動的に吸着・接続されます。
   * **自動接続**: レールを選択した状態でパーツパレットから次のレールを追加すると、進行方向に向かって自然に連続して繋がっていきます。
   * **回転再配置**: レール選択状態で `[`,`]` キーを押すと、接続する端点（ノード）を変更できます。
4. **レールの編集（切り取り・コピー・貼り付け・複製・削除）**:
   * 画面上部のツールバーボタン、右クリックメニュー（コンテキストメニュー）、または以下のショートカットキーで操作できます。
     * **元に戻す**: `Ctrl+Z`
     * **やり直し**: `Ctrl+Y`
     * **切り取り**: `Ctrl+X`
     * **コピー**: `Ctrl+C`
     * **貼り付け**: `Ctrl+V`
     * **複製**: `Ctrl+D`（コンテキストメニューまたはキーボード）
     * **削除**: `Delete` キー（画面上の削除ボタン、右クリックメニューも可）
5. **ジョイント表示の切り替え**:
   * ヘッダーの「ジョイント表示」セレクトボックスから、接続点（ノード）の表示モードを選択できます。
     * **全表示**: すべてのジョイントを表示します。
     * **レール端のみ**: レール端の主要ジョイントのみを表示します（デフォルト）。
     * **非表示**: ジョイント表示をすべて隠します。
6. **レイアウトの保存・読込**:
   * **JSON出力**: 現在のレイアウトデータをJSON形式でファイル出力・保存します。
   * **JSON読込**: 保存済みのJSONデータを読み込んでキャンバスに復元します。
   * **サンプル再読込**: デバッグ用のサンプルレイアウトを再読み込みします。

---

### 詳細オプション説明

パーツのノード（接続点）の位置や角度を微調整する機能です。

1. **ダイアログの表示**:
   * レールを選択した状態で、右クリックメニューから「オプション...」を選択するか、ショートカットキー `Ctrl+,`（カンマ）を押すと「パーツオプション」ダイアログが開きます。
2. **ノード位置・角度補正**:
   * 選択中のパーツに含まれるノードごとに、以下の入力項目が動的に表示されます。
     * **位置補正（前後・左右）**: ノードのオフセット位置（mm）を入力します。
     * **角度補正**: ノードの向き・接続角度（deg）を微調整します。
3. **保存とキャンセル**:
   * 「保存」ボタンをクリックすると補正値が適用されます。
   * 「キャンセル」ボタンをクリックすると変更を破棄してダイアログを閉じます。

## 編集者向けガイド（パーツ・システムの追加・編集）

### 1. 既存システムへ新パーツを追加する場合
各システム対応のカタログファイル（例: `rail-catalog-widetram.js` など）内の `registerRailParts({...})` にパーツ定義を追加します。

#### パーツ定義の構造例
```javascript
registerRailParts({
    "TOMIX-S140-WT": {
        systemId: "TOMIX-WIDETRAM-N",
        compatibleSystems: ["TOMIX-WIDETRAM-N"],
        category: "straight",
        name: "S140-WT",
        description: "ワイドトラムレール S140-WT(F)",
        nodes: [
            { "id": 0, "jointGroup": "rail-end", "relX": -70, "relY": 0, "facingAngle": 180 },
            { "id": 1, "jointGroup": "rail-end", "relX": 70,  "relY": 0, "facingAngle": 0 }
        ],
        shapes: [
            { "type": "line", "length": 140, "offsetX": 0, "offsetY": 0 }
        ]
    }
});

```

#### パラメータ詳細・記述観点一覧

| パラメータ | 必須/任意 | 型 | 意味と記述観点 |
| --- | --- | --- | --- |
| **`systemId`** | **必須** | `string` | 所属するレールシステムのID（`railCatalog.systems` のキーと一致させる）。 |
| **`compatibleSystems`** | **必須** | `array` | 接続互換性のあるシステムIDのリスト。基本は自身を含める。 |
| **`category`** | **必須** | `string` | 分類。現時点では `straight`（直線）, `curve`（曲線）, `turnout`（ポイント/分岐）に対応。 |
| **`name`** | **必須** | `string` | UI（パーツリスト）に表示される短縮表示名。 |
| **`description`** | 任意 | `string` | パーツの補足説明・正式名称。 |
| **`nodes`** | **必須** | `array` | 接続点ノードの配列。 |
| **`shapes`** | **必須** | `array` | キャンバス描画用の形状オブジェクト配列。 |

---

### 2. ノード（`nodes`）の設計ルールと自動接続ロジック

自動接続機能は、既存レール（親）と新規追加レール（子）の空きノードを探索して接続します。

パーツカタログを作成する際は、この接続評価順序アルゴリズムと以下のノードID割り当てガイドラインに従って設計してください。

> **例外について**: ターンテーブルやリバース線など、下記ルールを適用すると直感に反する挙動になる特殊パーツについては無理に従う必要はありません。主要な走行ラインを優先して個別にIDを設定してください。

#### 自動接続時のノード評価順序

* **親レール（選択中レール）**: **降順**で評価（最大ノードID → ... → Node 0）
* **子レール（追加するレール）**: **昇順**で評価（Node 0 → ... → 最大ノードID）

#### ノードID割り当てガイドライン（大きなIDほど優先度高）

1. **最大ノードID（主出口 / 最優先の延伸方向）**
* ユーザーが次にレールを伸ばしたいと思われる「主進行方向（直進・正面出口）」に割り当てます。
* 親レールの評価順序（降順）により最優先で検索されます。
* 例: 4ノードのパーツなら `Node 3`、6ノードのパーツなら `Node 5` を主出口とします。


2. **中間ノードID（副出口 / 分岐ルート）**
* ポイントの分岐曲線出口、渡り線ルート、副線側の出口などに割り当てます。
* 最大IDから下に向かって順番に（最大ID - 1, 最大ID - 2 ...）数値を割り当てます。


3. **Node 0 および 小さなノードID（主進入端 / 背面ノード）**
* パーツの左側・背面側に位置する進入側ノードに割り当てます。
* `Node 0` は原則として主進入端（入口）に割り当てます。親側としては最低優先度、子（新規レール）側としては最優先で選ばれるため、スムーズに接続されます。



> **注意**: ノード配列内の要素の記述順ではなく、各要素の **`id` プロパティの数値** で評価順序が判定されます。

#### `nodes` オブジェクトのプロパティ

* **`id`** *(必須)*: ノードID（数値）。上記のルールに従って割り当てます。
* **`jointGroup`** *(必須)*: ジョイント種別。通常のレール端面は `"rail-end"`。ワイドトラム等の側面ジョイントには `"widetram-side-..."` 等の識別名を使用。
* **`relX` / `relY`** *(必須)*: パーツの基準点 `(0, 0)` に対する接続点の相対座標（mm）。
* **`facingAngle`** *(必須)*: 接続面が向いている**外向きの絶対角度**（度数法。右向き `0`、下向き `90`、左向き `180`、上向き `-90`）。

---

### 3. 描画形状（`shapes`）と座標・角度の計算方法

パーツの基準点を原点 `(0, 0)` として各描画要素（`shapes`）のパラメータを計算します。  
基準点は必ずしもパーツ中心でなくても構いません。

描画要素は目的に応じて以下の描画タイプ（`type`）を使い分けます。

* **`line` / `arc`**: レール本体およびバラスト（道床）をまとめて一括描画するための標準形状です。
* **`polygon` / `path`**: ワイドレールの外付け道床や特殊構造物など、**レールを含まない単体の図形・道床のみ**を描画する場合に使用します。

---

#### 描画要素（`shapes`）の各パラメータ

##### 1. 直線 (`type: "line"`)

レール＋バラストを直線状にまとめて描画します。

* **`length`** *(必須)*: 全長（mm）。
* **`offsetX` / `offsetY`** *(任意)*: 基準点からのオフセット（デフォルトは `0`）。
* **`angle`** *(任意)*: 回転角度（度数法）。

##### 2. 円弧 (`type: "arc"`)

レール＋バラストを曲線状にまとめて描画します。

* **`radius`** *(必須)*: カーブの半径 $R$（mm）。
* **`arcAngle`** *(必須)*: 旋回角度（度数法。時計回り/右カーブは正数、反時計回り/左カーブは負数）。
* **`centerX` / `centerY`** *(必須)*: 円弧の**回転中心の座標**（後述する“第二の原点”）。
* **`startAngle`** *(必須)*: 円弧の描画を開始する中心角の角度（度数法）。

##### 3. 多角形 (`type: "polygon"`)

レール無しの平面図形（着脱式道床など）を描画します。

* **`points`** *(必須)*: 頂点座標の配列 `[ {x: x1, y: y1}, {x: x2, y: y2}, ... ]`。

##### 4. パス (`type: "path"`)

レール無しの複雑な曲線・境界線（多角形以外の形状）を描画します。

* **`d`** *(必須)*: SVG形式のパスコマンド文字列（例: `"M ... L ... A ... Z"`）。

---

#### 【設計者向け】カーブ・分岐パーツにおける「第二の原点」を用いた座標計算ガイド

ポイントや曲線パーツの `centerX` / `centerY` や各種接続ノード座標（`relX`, `relY`）は、**円弧の回転中心（第二の原点）を算出して極座標から逆算する**と正確に定義できます。

##### 座標系・角度の基本ルール

* 座標系：右 $+X$ / 下 $+Y$（HTML/SVG座標系）
* 角度基準：右 $= 0^\circ$ / 下 $= 90^\circ$ / 左 $= 180^\circ$ / 上 $= 270^\circ$（$-90^\circ$）

##### 右カーブ（下方向へ曲がる場合）

パーツ基準点 `(0, 0)`、進入端 `Node 0`（$-L/2, 0$）、半径 $R$、旋回角 $\theta$（正の値）：

1. **第二の原点（`centerX`, `centerY`）**: 進入端 `(-L/2, 0)` から真下（$+Y$）に距離 $R$ 離れた位置。
* $centerX = -\frac{L}{2}$
* $centerY = R$
* $startAngle = 270^\circ$（真上向き）


2. **分岐端・ノード座標計算**: 第二の原点からの極座標移動量を加算。
* $\Delta X = R \cdot \sin(\theta)$
* $\Delta Y = -R \cdot \cos(\theta)$
* $relX = centerX + \Delta X = -\frac{L}{2} + R \cdot \sin(\theta)$
* $relY = centerY + \Delta Y = R - R \cdot \cos(\theta)$



##### 左カーブ（上方向へ曲がる場合）

パーツ基準点 `(0, 0)`、進入端 `Node 0`（$-L/2, 0$）、半径 $R$、旋回角 $-\theta$：

1. **第二の原点（`centerX`, `centerY`）**: 進入端 `(-L/2, 0)` から真上（$-Y$）に距離 $R$ 離れた位置。
* $centerX = -\frac{L}{2}$
* $centerY = -R$
* $startAngle = 90^\circ$（真下向き）


2. **分岐端・ノード座標計算**:
* $\Delta X = R \cdot \sin(\theta)$
* $\Delta Y = R \cdot \cos(\theta)$
* $relX = centerX + \Delta X = -\frac{L}{2} + R \cdot \sin(\theta)$
* $relY = centerY + \Delta Y = -R + R \cdot \cos(\theta)$



##### 補足：道床内側・外側側面ノードの計算

※ワイドレールの着脱用側面ジョイント等の位置は、道床厚み $d$ に応じて半径を $R \pm d$ に変更し、任意の中間角度（例: $\theta / 2$）を代入して計算します。

### 4. 新しいレールシステム（規格）を新規追加する場合

新しいメーカーや規格（例: TOMIXのHOゲージシステム等）を追加する場合は、個別のパーツカタログファイルを作成する前に、**カタログコア（`rail-catalog-core.js` 等）の `railCatalog.systems` に定義を追加**してください。

#### カタログコアへの登録例

```javascript
const railCatalog = {
    systems: {
        // ...既存システム...

        // 1. ここに新規システムを追加定義
        "TOMIX-HO-N": {
            scale: "HO",                           // スケール ("N", "HO" 等)
            brand: "TOMIX",                        // ブランド/メーカー名
            systemName: "HOレール",                // UI表示用のシステム名
            gauge: 16.5,                           // 軌間 (mm)
            ballastWidth: 30,                      // 道床幅 (mm)
            connectorType: "tomix-ho-connector",   // コネクタ規格名
            libraryFile: "rail-catalog-tomix-ho.js" // 読み込むJSファイル名
        }
    },
    items: {}
};

```

登録後、指定した `libraryFile`（例: `rail-catalog-tomix-ho.js`）を新規作成し、そのファイル内で `registerRailParts({...})` を使用してパーツを定義していきます。

## トラブルシューティング（編集者向け）

* **パーツIDの重複に注意**: 同一ファイル内または複数ファイル間で同じパーツID（例: `"TOMIX-C103-30-WT"`）を複数回定義すると、JavaScriptのオブジェクト仕様上、**後ろに記述された定義で上書き**されます。パーツが出ない・設定が反映されない場合はIDの重複を確認してください。
* **逆向き接続が発生する場合**: ノードの `facingAngle` が180度反転していないか、または `id` の設定が逆になっていないか確認してください。
