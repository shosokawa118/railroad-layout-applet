# Railroad Layout Applet (RLA)

Nゲージなどの鉄道模型レールをキャンバス上で直感的に配置・接続し、レイアウトを設計できるWebアプレットです。  
パーツ同士のジョイント吸着（スナップ接続）や、選択中のレールから連続して繋がっていく自動接続機能、各種レールシステムのカタログ拡張に対応しています。

---

## 主な機能・特徴

* **直感的な操作**: マウスドラッグでレールを自由に配置・移動・回転
* **スマート接続機能**:
  * ジョイント同士を近接させることによるスナップ接続
  * 既存レールを選択した状態での連続自動接続
---

## 利用方法（操作ガイド）

### 基本操作
1. **パーツの追加**: 画面上のパーツリストから設置したいレールを選択してキャンバスに追加します。
2. **パーツの移動・回転**:
   * **移動**: レールをドラッグ＆ドロップします。
   * **回転**: レールを選択し、回転ハンドルを操作します。
   * 範囲選択でまとめて移動・回転することもできます。
3. **レールの接続**:
   * **手動スナップ**: レールの端点（ノード）を別のレールの端点に近づけると自動的に吸着・接続されます。
   * **自動接続**: レールを選択した状態でパーツリストから次のレールを追加すると、進行方向に向かって自然に連続して繋がっていきます。

## 編集者向けガイド（パーツ・システムの追加・編集）

### 1. 既存システムへ新パーツを追加する場合
各システム対応のカタログファイル（例: `rail-catalog-widetram.js` など）内の `registerRailParts({...})` にパーツ定義を追加します。

#### パーツ定義の構造例
```javascript
registerRailParts({
    "TOMIX-S140-WT": {
        systemId: "TOMIX-WIDETRAM-N",
        compatibleSystems: ["TOMIX-WIDETRAM-N"],
        category: "straight",
        name: "S140-WT",
        description: "ワイドトラムレール S140-WT(F)",
        nodes: [
            { "id": 0, "jointGroup": "rail-end", "relX": -70, "relY": 0, "facingAngle": 180 },
            { "id": 1, "jointGroup": "rail-end", "relX": 70,  "relY": 0, "facingAngle": 0 }
        ],
        shapes: [
            { "type": "line", "length": 140, "offsetX": 0, "offsetY": 0 }
        ]
    }
});
```

#### パラメータ詳細・記述観点一覧

| パラメータ | 必須/任意 | 型 | 意味と記述観点 |
| :--- | :---: | :---: | :--- |
| **`systemId`** | **必須** | `string` | 所属するレールシステムのID（`railCatalog.systems` のキーと一致させる）。 |
| **`compatibleSystems`** | **必須** | `array` | 接続互換性のあるシステムIDのリスト。基本は自身を含める。 |
| **`category`** | **必須** | `string` | 分類。現時点では `straight`（直線）, `curve`（曲線）, `turnout`（ポイント/分岐）に対応。 |
| **`name`** | **必須** | `string` | UI（パーツリスト）に表示される短縮表示名。 |
| **`description`** | 任意 | `string` | パーツの補足説明・正式名称。 |
| **`nodes`** | **必須** | `array` | 接続点ノードの配列。 |
| **`shapes`** | **必須** | `array` | キャンバス描画用の形状オブジェクト配列。 |

### 2. ノード（`nodes`）の設計ルールと自動接続ロジック

自動接続機能は `1 → 2 → ... → 最大ID → 0` という優先順位で空きノードを探索します。  
パーツカタログを作成する際は、この接続優先度ロジックと以下の配置ルールに従ってノードIDを設定してください。

#### ノードIDの設定・配置ガイドライン

* **`id: 0`（主進入端 / 戻り方向 / 優先度最低）**
  * レールの標準的な「入口（進入側）」ノードです。原則として**パーツの左側**に配置します。
  * ※進行方向と逆向きに自動接続されるのを防ぐため、探索優先度は最も低く評価されます。
* **`id: 1`（主進行端 / 最優先）**
  * `id: 0` から進入して**直進（正対）して抜ける出口**ノードです。自動接続時に最優先で選ばれます。
  * 直進線がないパーツ（カーブポイント等）の場合は、編集者の主観で「より主線（直進）っぽい方」（大半径側など）を `id: 1` に指定します。
* **`id: 2` 以降（右側 / 出口側のノード）**
  * `id: 0` から分岐する出口、または `id: 1` と同じ側（右側）にあるノードは、**「上から下」の順**に連番（2, 3, 4...）を割り当てます。
  * ※ `id: 0` と直接繋がっていない複線・交差パーツの右側ノードも含みます。
* **末尾の番号（左側 / 2番目以降の進入端）**
  * 複線や渡り線などで `id: 0` と同じ側（左側）に複数のノードが存在する場合、それらは**「下から上」の順**に連番を割り当てます。
  * ※この設定により、自動接続の探索順（`1 → 2 → ... → 最大ID → 0`）において、右側の出口ノードが全滅した後に「左側の下側ノード」→「左側の `id: 0`」の順で評価されます。

> **例外について**: ターンテーブルやリバース線など、上記ルールを適用すると直感に反する挙動になる特殊パーツについては無理に従う必要はありません。主要な走行ラインを優先して個別にIDを設定してください。

> **注意**: ノード配列内の要素の並び順ではなく、各要素の **`id` プロパティの数値** で優先度が判定されます。

#### `nodes` オブジェクトのプロパティ
* **`id`** *(必須)*: ノードID（数値）。上記のルールに従って割り当てます。
* **`jointGroup`** *(必須)*: ジョイント種別。通常のレール端面は `"rail-end"`。ワイドトラム等の側面ジョイントには `"widetram-side-..."` 等の識別名を使用。
* **`relX` / `relY`** *(必須)*: パーツの中心 `(0, 0)` を基準とした接続点の相対座標（mm）。
* **`facingAngle`** *(必須)*: 接続面が向いている**外向きの絶対角度**（度数法。右向き `0`、下向き `90`、左向き `180`、上向き `-90`）。

### 3. 描画形状（`shapes`）と座標・角度の計算方法

パーツの中心を原点 `(0, 0)` として各パラメータを計算します。

#### 直線 (`type: "line"`)
* **`length`** *(必須)*: 全長（mm）。
* **`offsetX` / `offsetY`** *(任意)*: 中心からのオフセット（デフォルトは `0`）。
* **`angle`** *(任意)*: 回転角度（度数法）。

#### 円弧 (`type: "arc"`)
* **`radius`** *(必須)*: カーブの半径 $R$（mm）。
* **`arcAngle`** *(必須)*: 旋回角度（度数法。時計回り/右カーブは正数、反時計回り/左カーブは負数）。
* **`centerX` / `centerY`** *(必須)*: 円弧の**中心点（回転軸）の座標**。
  * 【計算例】半径 $R$、旋回角 $\theta$ の場合：  
    $centerX = 0$, $centerY = R \cdot \cos(\theta / 2)$ などを幾何学的に算出。
* **`startAngle`** *(必須)*: 円弧を描画開始する中心角の角度（度数法）。

#### カーブ・分岐パーツにおける「第二の原点」を用いた座標計算のアドバイス

ポイントレールや複線カーブなど、直線と曲線が混在するパーツの接続ノード座標（`relX`, `relY`）や描画中心（`centerX`, `centerY`）を計算する際は、**「円弧の回転中心（第二の原点）」を設定して極座標から逆算する**と精度が高くスムーズに設計できます。

##### 1. HTML/SVG座標系における角度と方向
* 座標系：右 $+X$ / 下 $+Y$
* 基準角：右 $= 0^\circ$ / 下 $= 90^\circ$ / 左 $= 180^\circ$ / 上 $= 270^\circ$（$-90^\circ$）

##### 2. 右カーブ（下方向へ曲がる）の計算手順
パーツの中心 `(0, 0)`、進入端 `Node 0`（$-L/2, 0$）とし、半径 $R$、中心角 $\theta$ の場合：

1. **第二の原点（円弧の中心）を設定**:  
   進入端 `(-L/2, 0)` から真下（$+Y$方向）に距離 $R$ 離れた位置を中心座標とします。
   * $centerX = -L/2$
   * $centerY = R$
   * 円弧の開始角度 $startAngle = 270^\circ$（真上向き）

2. **カーブ出口ノード（分岐端など）の相対座標計算**:  
   第二の原点からの極座標変換により求めます。
   * $\Delta X = R \cdot \sin(\theta)$
   * $\Delta Y = -R \cdot \cos(\theta)$
   * **ノード座標**: 
     $$relX = centerX + \Delta X = -\frac{L}{2} + R \cdot \sin(\theta)$$
     $$relY = centerY + \Delta Y = R - R \cdot \cos(\theta)$$

##### 3. 左カーブ（上方向へ曲がる）の計算手順
1. **第二の原点（円弧の中心）**:  
   進入端から真上（$-Y$方向）に距離 $R$ 離れた位置を中心に設定。
   * $centerX = -L/2$
   * $centerY = -R$
   * 円弧の開始角度 $startAngle = 90^\circ$（真下向き）

2. **カーブ出口ノードの相対座標計算**:  
   * $\Delta X = R \cdot \sin(\theta)$
   * $\Delta Y = R \cdot \cos(\theta)$
   * **ノード座標**: 
     $$relX = centerX + \Delta X = -\frac{L}{2} + R \cdot \sin(\theta)$$
     $$relY = centerY + \Delta Y = -R + R \cdot \cos(\theta)$$

##### 補足：道床内側・外側側面ノードの計算
ワイドレール等の側面ジョイント座標を算出する場合は、道床半幅 $d$ に応じて半径を $R_{\text{inner}} = R - d$ や $R_{\text{outer}} = R + d$ に変更し、目的の角度 $\theta_{\text{mid}}$（例：中間点の $7.5^\circ$ など）を代入して同様に計算します。

### 4. 新しいレールシステム（規格）を新規追加する場合

新しいメーカーや規格（例: TOMIXのHOゲージシステム等）を追加する場合は、個別のパーツカタログファイルを作成する前に、**カタログコア（`rail-catalog-core.js` 等）の `railCatalog.systems` に定義を追加**してください。

#### カタログコアへの登録例
```javascript
const railCatalog = {
    systems: {
        // ...既存システム...

        // 1. ここに新規システムを追加定義
        "TOMIX-HO-N": {
            scale: "HO",                           // スケール ("N", "HO" 等)
            brand: "TOMIX",                        // ブランド/メーカー名
            systemName: "HOレール",                // UI表示用のシステム名
            gauge: 16.5,                           // 軌間 (mm)
            ballastWidth: 30,                      // 道床幅 (mm)
            connectorType: "tomix-ho-connector",   // コネクタ規格名
            libraryFile: "rail-catalog-tomix-ho.js" // 読み込むJSファイル名
        }
    },
    items: {}
};
```

登録後、指定した `libraryFile`（例: `rail-catalog-tomix-ho.js`）を新規作成し、そのファイル内で `registerRailParts({...})` を使用してパーツを定義していきます。

## トラブルシューティング（編集者向け）

* **パーツIDの重複に注意**: 同一ファイル内または複数ファイル間で同じパーツID（例: `"TOMIX-C103-30-WT"`）を複数回定義すると、JavaScriptのオブジェクト仕様上、**後ろに記述された定義で上書き**されます。パーツが出ない・設定が反映されない場合はIDの重複を確認してください。
* **逆向き接続が発生する場合**: ノードの `facingAngle` が180度反転していないか、または `id` の設定（0と1）が逆になっていないか確認してください。
